## 🎨 设计规范

### 颜色方案
- 主色：`#1890ff` (蓝色)
- 辅助色：
  - `#52c41a` (绿色) - 成功、收入
  - `#ff4d4f` (红色) - 失败、支出
  - `#faad14` (橙色) - 警告
- 背景色：`#f5f5f5` (浅灰)
- 文字色：`#333333`、`#666666`、`#999999`

### 字体规范
- 主标题：20px, 粗体
- 副标题：16px, 粗体
- 正文：14px, 常规
- 辅助文字：12px, 常规

### 间距规范
- 页面边距：24px
- 模块间距：24px
- 卡片间距：20px

## 📱 响应式设计

### 断点
- 大屏：≥ 1400px (每行 5 个卡片)
- 中屏：1200px - 1399px (每行 4 个卡片)
- 小屏：< 1200px (每行 3 个卡片)

### 适配策略
- 使用 CSS Grid 和 Flexbox
- 媒体查询 (@media) 实现响应式
- 图片自适应缩放

## 🔧 开发建议

1. **组件化开发**
   - 将导航栏、卡片、按钮等拆分为独立组件
   - 复用性高，易于维护

2. **性能优化**
   - 图片懒加载
   - 代码分割
   - 虚拟滚动 (长列表)

3. **SEO 优化**
   - 合理使用 meta 标签
   - 语义化 HTML
   - 服务端渲染 (SSR)

4. **测试**
   - 单元测试
   - 集成测试
   - E2E 测试
